Code Crucible: Backend
This project leverages the following core technologies to build a lightweight and efficient backend API:

Node.js:
Node.js is an open-source, cross-platform JavaScript runtime environment that executes JavaScript code outside a web browser. It's ideal for building scalable network applications due to its event-driven, non-blocking I/O model. In this project, Node.js provides the execution environment for our server-side JavaScript code.

Express.js:
Express.js is a minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications. It simplifies the process of building web servers and APIs by offering a powerful routing system, middleware support, and template engine integration. Here, Express.js is used to define the /greet route and handle incoming HTTP requests efficiently
